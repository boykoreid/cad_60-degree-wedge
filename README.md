# Fusion 360 Project: 60° Golf Wedge Model

## Overview
This project is a 3D CAD model of a 60-degree golf wedge created in Autodesk Fusion 360. The model was developed by referencing my own personal wedge to estimate dimensions and proportions, then recreating the club as a detailed model.

## Features
This model incorporates several complex CAD techniques, including:

### Loft Features
Used to create complex curved geometry, particularly in the club head

<br />

### Angled Construction Planes
Custom planes were created at specific angles to define the wedge’s loft and support feature placement.

<br />

### Parametric Sketching and Constraints
Dimensions were estimated from a physical wedge and applied using constrained sketches for consistency.

<br />

### Assembly Modeling
The wedge was modeled as an assembly of four separate components:
- Shaft: Main body of the club
- Grip: Handle component modeled with detailed profile features
- Head: 60-degree wedge head geometry
- Pin: Connects components within the assembly


## What I Learned
Through this project, I improved my understanding of:
- Advanced lofting techniques
- Construction plane creation and reference geometry
- Reverse engineering dimensions from a physical object
